# 开题提纲与质询


先从学校原始模板提取章节、字数、附件、时间及评分要求，再填写正式提纲。

备用逻辑：问题重要性 → 已知与缺口 → 科学问题 → 假说/目标 → 研究设计与统计 → 创新 → 可行性与风险 → 进度 → 参考文献。

## 优先质询

1. 这个问题解决后改变什么认识？
2. 最接近的研究已经做到了哪里？
3. 什么结果可以反驳你的核心解释？
4. 哪个对照或设计能排除最重要的替代解释？
5. 样本、模型和终点是否真正回答原问题？
6. 关键资源的可用性有什么依据？
7. 如果第一步失败，剩余研究如何调整？
