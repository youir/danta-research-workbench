# 长期记忆维护 / Memory Protocol

## 读取

先读 AGENTS、首页、Path-Map、当前状态与Idea；与任务有关时再读本目录索引、稳定背景、未闭环事项和交接，最后回查来源。不要每轮加载全库。

## 写入阈值

只有明确长期偏好/约束、已验证的可复用方法、重要取舍及理由、跨会话未决事项才入库。优先更新已有条目；大段方法移到方法区，本处仅指针。项目事实在项目文件，知识解释在Wiki，具体决定在决策日志，避免记忆复制所有东西。

每条记忆附来源位置、日期、适用范围、证据类型及复核条件。推断永远标推断；不因重复出现就变成事实。遇到冲突同时保留冲突双方的来源，核实后注明替代关系。

龚博士的研究画像与博士助理协作偏好记录在主课题“研究背景/研究画像”中，作为唯一权威入口。初始化资料由工作台准备者提供时标为“待龚博士核实”；本人明确确认后再改状态。逐步记录语言、详略、反馈方式与支持偏好，不从私人聊天、日记或未授权目录推断；不复制到稳定背景形成双份记录。龚博士可要求修改或删除。

## 收尾

问：值得以后再用吗？已有权威位置吗？来源能定位吗？下次要核实什么？只保存必要小段；无长期价值就不新增。旧信息标过时不擦除原记录。不要保存账号凭证、患者身份、完整聊天或临时情绪。

这是文件驱动的记忆，不保证模型跨会话自动记住；未读取就不能声称记得。
