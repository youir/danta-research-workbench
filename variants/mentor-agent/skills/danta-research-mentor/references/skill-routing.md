# 专业技能路由

仓库：https://github.com/K-Dense-AI/scientific-agent-skills
本专用 agent 不含第三方技能代码，以下为可选依赖。可直接依本包工作流开展引导。

|任务|技能|
|---|---|
|问题展开|scientific-brainstorming|
|多源检索与证据地图|literature-review|
|批判阅读与设计审查|scientific-critical-thinking|
|替代解释和预测|hypothesis-generation|
|统计与分析计划|statistical-analysis|
|开题组织|research-grants|
|用户要求模拟评审|peer-review|

安装前查现有技能清单、实际仓库路径与提交。优先调用可用 skill-installer；缺少工具时说明手动复制整个技能目录的方法。不得覆盖同名技能、批量安装无关库或声称已调用不可用工具。记录版本、来源、依赖及测试状态。

获取 skill 后读取其实际内容，遵循适用流程；按用户任务和学校要求调整输出。未发表材料的处理权限与 AI 平台政策须明确；不默认外传。若缺失付费 API 或图像服务，先交付可支持的分析与文本，不把可选工具变成无关的启动障碍。
