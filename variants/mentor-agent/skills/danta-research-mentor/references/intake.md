# 首次盘点与阶段入口

## 首次资料扫描：授权门槛

可主动提出一次可选的科研资料扫描，帮助使用者更快建立课题与工作画像；提出建议不代表获得授权。读取内容或递归列出文件前，必须先取得龚博士本人对具体路径、子目录/文件类型、扫描目的，以及在私有知识库新建摘要报告的明确同意。亲友、部署者的同意不替代她本人授权。含糊的“看看我的资料”不能扩展成整机或整个云盘扫描。

授权时说明扫描只读、原件不改动，列明默认排除的聊天/邮件、个人文件、患者可识别信息、凭据和原始数据，并如实说明当前 Codex/模型处理是否涉及云端或第三方；若可能对外传输，必须在披露后另行取得明确同意。处理位置无法确认时不承诺本地处理；不同意时不扫描，改用用户主动提供的材料。

授权后严格限于许可范围，登记实际读取的文件、类型、覆盖深度、跳过项与解析失败。摘要逐条标注来源，将材料明确内容与推断分开；只新建/更新资料掌握报告，不把推断直接升级为研究画像事实。交龚博士核对后，才把确认内容写入画像、资源或长期记忆。不得把原件移动、改名、修改、删除或上传。

## 范围

先问或从会话中确定课题目录和本轮目标。只读取用户指定资料；没有资料时输出清单，不虚构已阅读。建立文件索引：路径/名称、版本、资料类型、阅读范围、核心内容、影响、待核实点。扫描件或附件解析不完整时指出具体缺页，不能把“文件已打开”写成“已掌握”。

阅读优先级：学校要求和时间 → 导师真实意见与现有计划 → 资源清单 → 最相关原始研究 → 预实验方法与结果。原始数据先了解字典、结构、单位和质量，再选择分析；不无目的读取全部数据。

## 要了解的条件

研究兴趣与疾病方向、问题来源、导师主线、已有发现；样本来源与规模、模型成熟度、平台与技术人员、合作可及性、经费、时间、伦理与数据使用边界；学校格式与考核要求。字段状态为已确认/暂定/未定/待核实，均有来源。公开论文不能证明当前实验室具备同样资源。

若龚博士希望快速整理既有文章和工作材料，先按上面的授权门槛完成一次初始扫描。扫描授权只限说清的文件夹、类型、目的与报告保存位置。报告区分材料原文事实和助理推断，逐项留来源与阅读范围；经龚博士核对后再更新正式画像。患者可识别信息、原始数据、凭据、聊天/邮件及个人文件默认排除；若模型内容处理会经云端或第三方，先披露并单独征求同意。

## 环境检查

优先检查当前工具清单、指定技能文件和项目说明。只在任务需要时检查 Python/R 或软件版本；不读取凭据、浏览器个人资料或整机环境变量。记录文献检索、全文阅读、文件解析、数据分析、作图和文档输出分别是可用/未测试/不可用，以及证据。离线时可做本地盘点，查新状态标为未完成。

## 盘点交付

输出“我已掌握什么、哪些材料未读完整、哪些条件未确认、这些缺口会影响什么”。优先解决最多三个阻塞问题。可以进入候选探索的条件：问题范围或兴趣、实际资源边界、时间目标至少已被记录，未知信息的影响已说明；不能将纯方法练习当作正式推荐。

情形处理：
- 只有导师姓名：确认身份背景后收集个人研究条件，不替用户选疾病。
- 用户说直接给题：可提供明确标为假设前提的候选，不宣称可行或已查新。
- 资源与文献矛盾：以本项目资源的直接信息为准，记录差异。
- 已经开题：先盘点现有批准方案与当前瓶颈，无需重新选题。

用户尚无方向也可先获得帮助：直接解释概念或示范如何拆解一段材料，明确示例是假想，不写入真实画像。资源未定限制的是可行性结论，不是知识解释和暂定问题比较。不要把盘点变成必须先回答完的问卷。
