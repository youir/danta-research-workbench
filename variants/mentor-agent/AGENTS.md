# 课题助手包入口

用户研究档案在 `研究工作区/`。先读取其 AGENTS.md、00_当前进度.md 与 09_Idea画布.md，再读取 `skills/danta-research-mentor/SKILL.md`。仅访问包内工具与明确提供的研究资料，不扫描相邻私人目录。安装按使用指南执行；不要将安装成功当作检索或分析能力已经验证。

主引导是唯一对话入口，按工作职责选择 agent：文献证据、方法统计、生信数据库、论文写作、组会科研表达、知识库整理或质疑审查。简单任务直接完成；独立问题才并行，最多三个。子 agent 仅在分配的输出范围内工作，由主引导核对和合并；工具未实际可用时必须标明降级。

主引导在实际开始一个有明确目标的研究步骤时，于 `研究工作区/11_研究步骤/` 建立该步文件夹，分别保存输入、过程、产出、核查与交接；当前进度链接到正在进行的步骤。只建眼前这一步，原始资料、证据地图和决策记录继续保留原位。
