# 蛋挞的课题助手

这是陪你从资料盘点、选题走到开题和课题推进的 agent 配置包。它需要 Codex 或其他能读取文件的 AI 助手运行，本身不是独立软件，不会自动定时工作。

## 第一次使用：三个动作

1. 解压整个压缩包，保留目录结构。把 `研究工作区` 文件夹作为 Codex 项目打开。不要把它与私人聊天记录或无关资料混在一起。
2. 给 AI 发送下面的启动语。它可以先直接读取相邻的 skill；如果需要安装，使用下文的离线安装方式。
3. 按 AI 引导逐步补资料。研究方向和实验条件可以填“未定”，不需要一次准备完。

### 复制这段启动语

> 请读取当前项目的 AGENTS.md 和上一级 skills/danta-research-mentor/SKILL.md，作为我的课题助手开始工作。先盘点我提供的资料、研究资源和可用工具，建立资料掌握报告；不要直接给我拟定最终课题。每轮最多问三个关键问题。导师公开研究资料只能作为参考，具体安排以我提供的指导意见为准。请把进度写入工作区，下次从记录继续。

若工具无法访问上一级文件夹，把 `skills/danta-research-mentor` 整个文件夹复制进你的项目，再给出它的实际路径。只有聊天功能时，上传本包的 SKILL.md、references 及相关模板；无法持久写文件的聊天工具需要你保存每次输出的交接记录。

## 离线安装 agent skill（推荐）

安装仅复制本包的专用 skill，不联网、不安装 Python 库、不覆盖已有同名内容。需 Python 3.9 或以上。

在本包根目录运行：

```bash
python3 install_agent.py --dry-run
python3 install_agent.py
```

Windows 可用 `py -3 install_agent.py`。不会使用终端时，直接让 Codex：“请检查 install_agent.py，再运行它安装本包的课题助手 skill。”

默认位置为 `$CODEX_HOME/skills`，没有该变量时为 `~/.codex/skills`。安装成功后在下一轮尝试：

> 使用 $danta-research-mentor，先读研究工作区的进度记录，再继续协助我的课题。

如果技能尚未显示，打开新任务后重试；也可以继续用文件路径显式加载。可用 `--dest <技能目录>` 安装到自己指定的位置。安装不会创建新任务、修改其他技能或设置自动运行。

## 先放哪些资料

将获准用于当前 AI 环境的资料放入 `研究工作区/资料入口`，按类型建文件夹即可：

- 学校开题模板、时间与考核要求。
- 导师实际指导意见、课题组研究介绍。
- 你认为关键的论文、综述和引用导出文件。
- 已有研究计划、预实验及其方法说明。
- 样本、模型、仪器、技术人员、合作与经费清单。

患者资料先去标识；涉密或受限材料不要放入未经批准的 AI 环境。文件在本地不意味着读取它的云端模型也在本地运行；可先只提供获准分享的摘要和资源清单。

## 第一次工作应得到什么

AI 应输出：资料目录与阅读状态、已确认的研究条件、工具可用性、尚缺的关键资料、下一步最少问题。没有完成这一步，就不应声称“已充分了解条件”。有缺口时可以讨论条件性方向，但不应替你决定最终课题。

## 之后可以这样用

- “新增两篇论文，更新证据地图，告诉我哪些判断改变了。”
- “按导师今天的意见调整方案，保留变更原因。”
- “比较这三个候选题，重点看可行性和关键证据。”
- “模拟开题评审，先找出最可能被追问的三点。”
- “这是本周实验结果，区分观察、解释和下一步验证。”
- “帮我写本周组会汇报，只使用已有证据。”

专业 GitHub skills 的对应关系与安装引导见 `01_扩展技能安装.md`。本包可以独立进行引导与论证，不以扩展技能全部安装为启动条件。

版本：1.1；优化日期：2026-09-24。研究视角卡是公开资料的有限归纳，不是对教授人格、真实评审意见或最新全部研究的复现。

## 本版的讨论方式

先听你想不明白的现象，再用少量追问、知识解释和证据帮助你形成自己的判断。Idea 画布记当前理解；证据地图记来源；决策记录只记你或导师实际作出的决定。三个检查节点可以回看和修改，不必逐项点头才能继续推演。已有同名旧 skill 时安装器会报告冲突；备份旧技能到发现目录之外再安装新版，不覆盖真实研究记录。本包不创建或迁移已有日报自动化。

## 让多个 agent 一起帮你思考

可复制 `05_多Agent使用指南.md` 的启动语。主引导与你对话，文献、方法和质疑专家按需参与；先确认工具实际可用。Skills 安装包与 agent 角色配置均在本包内，二者作用不同。
