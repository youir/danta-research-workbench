# 按任务安装扩展科研 skills

本包自带的 danta-research-mentor 是工作流入口。以下第三方 skills 来自 [K-Dense-AI/scientific-agent-skills](https://github.com/K-Dense-AI/scientific-agent-skills)，本包不捆绑其代码，不声明已安装，也不把它们当作教授本人提供的技能。

|阶段|名称|作用|
|---|---|---|
|问题探索|scientific-brainstorming|展开候选问题和记录假设|
|文献核查|literature-review|检索、筛选与引用核实|
|证据审查|scientific-critical-thinking|偏倚、混杂和结论强度|
|研究假说|hypothesis-generation|替代解释和可区分预测|
|分析规划|statistical-analysis|终点、统计模型与功效规划|
|开题组织|research-grants|目标、重要性、可行性与里程碑|
|模拟评审|peer-review|方案和论证审查|

每个文件的地址形式为 `https://github.com/K-Dense-AI/scientific-agent-skills/blob/main/skills/名称/SKILL.md`。路径依据本次公开页面核查；上游可能更新，安装前必须核对实际路径与提交。

## 给 Codex 的安装指令

> 使用当前可用的 skill-installer，从 K-Dense-AI/scientific-agent-skills 安装上述科研技能。先检查已有同名技能，保留已有版本；读取实际 SKILL.md 与所需依赖，记录 Git 提交版本。使用 skill-installer 自带的 install-skill-from-github.py，把 --repo 设为 K-Dense-AI/scientific-agent-skills，--path 设为实际核实的各技能目录，--ref 设为已经核实的提交 SHA。安装到当前用户技能目录。报告每项成功、已有或失败状态。不要为了安装说明文件而安装整套分析库、配置付费 API 或上传研究资料。

如果当前环境没有 skill-installer，可在 GitHub 下载指定版本仓库，将所需技能的整个文件夹（保留 scripts、references 和 assets）复制到 Codex 技能目录。只复制 SKILL.md 可能导致引用缺失。

## 安装不等于可运行

在 `研究工作区/02_环境与资料掌握报告.md` 为每项记录：名称、来源、提交、安装路径、说明是否读过、依赖是否具备、做过什么检查、失败原因。将“说明可读取”“已安装”“实际执行成功”分开。

开始文献工作时检查检索工具与全文访问；开始分析时才核实 R/Python、相应包及数据。网络不可用时可以盘点本地资料，不可假装完成文献查新。收费服务缺失时提供当前可用替代途径。

不将第三方 skill 的基金模板直接当成学校开题模板；不因为技能提出可视化就编造数据图。技术操作必须符合所在实验室与平台的实际条件。
