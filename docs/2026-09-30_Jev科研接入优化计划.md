# Jev 接入科研工作台：复用与优化计划

更新日期：2026-09-30。范围是公开文献检索、文献库归类建议和证据核对；不把 Jev 当作检索引擎、科研结论生成器或自动整理私有库的代理。

## 现状与选择

| 能力 | 已有方案 | 本工作台决定 |
|---|---|---|
| 公开检索后的相关性排序、网页筛查、主张核对 | 工作台已配置社区 [`jev-mcp`](https://github.com/jkudish/jev-mcp)，但工具必须在当前客户端实际可调用 | 保留现有搜索源和 Jev 可选后处理；不可用时继续原流程 |
| 已有 Zotero 文献的分类 | [Jadense in Zotero](https://github.com/jadense-ai/jadense-in-zotero/blob/main/CHANGELOG.md) 有选文、候选目录、推荐预览、应用和撤销；分类单独使用 TypeSafe | 若龚博士使用 Zotero，优先评估插件，不在桌面工作台再建一个文献库写入器 |
| Jev 判定问题与阈值设计 | [TypeSafe 官方 Skill](https://github.com/typesafe-ai/skills)、[官方分类示例](https://docs.typesafe.ai/cookbooks/hierarchical_classification)、[tenbin](https://github.com/simota/tenbin) | 复用设计方法；tenbin 只在开发评估时考虑，不列为用户安装项 |
| 文献筛选与主张核查提示 | [jev-skill](https://github.com/wuyoscar/jev-skill) 给出文献筛选、主张对照的样例，但相关配方注明未逐项评估 | 只借鉴判定问题和失败边界，不整包安装或宣称已验证 |
| 系统综述逐字段提取 | [jev-reviewer](https://github.com/choxos/jev-reviewer) 支持逐处引用和人工核对 | 等确有系统综述任务再单独试用；文本与问题会发往 TypeSafe，不能以“文件留在浏览器”解释成离线处理 |

## 使用逻辑

1. **检索**：先由 PubMed、Consensus、Semantic Scholar 等实际来源召回。公开候选不少于 4 条时，若 Jev MCP 真实可用且内容可外发，最多对 20 条短摘要重排。保留原始顺序与来源映射；仍打开原文核查。
2. **收藏**：新检索结果先核验元数据和阅读价值，再由实际 Zotero 操作保存。Jev 排序不代表已收藏或已证明质量。
3. **整理**：只有在龚博士明确要求整理已有 Zotero 条目、确认候选收藏夹及外发范围后才生成分类预览。预览包含原目录、建议目录、无匹配、疑难项；归档动作与分类判断分开。当前工作台不直接读写 Zotero 数据库。
4. **证据**：公开原文的具体主张可用 `jev_verify` 辅助查错，最终仍由人核对研究设计、指标、图表与原文上下文。分类、相关性和置信度都不是证据质量分。

## 分阶段实施

| 阶段 | 实施内容 | 完成条件 |
|---|---|---|
| A. 本次 | 更新主 Skill 路由和 Jev 说明；修复一处把来源 ID、链接发往 Jev 的相互矛盾的说明 | 文档统一使用临时 ID；Zotero 与 Obsidian 的授权边界明确；无实机功能声明 |
| B. 龚博士本机试点 | 先确认是否使用 Zotero、版本、文献规模、现有收藏夹；如需要，由她选择试用 Jadense 并在少量非敏感文献上预览 | 能导出或截图“原目录—建议—无匹配—最终选择”；未确认前不应用更改；撤销路径可用 |
| C. 效果评估 | 从她愿意处理且可外发的文献里取小批人工标注集，覆盖病理学研究常见的交叉主题、阴性结果、方法论文和无匹配项；比较人工基线与 Jev 建议 | 记录错放、漏放、无匹配及人工修改；按错误成本决定是否继续使用，不直接套用示例阈值 |
| D. 必要时扩展 | 只有 Zotero 插件不能满足与工作台研究记录的衔接时，才设计最小的导入/导出或索引适配 | 先明确数据格式、备份与撤销；不得直接修改 Zotero SQLite 或私有 Obsidian 库 |

## 不先做的事

- 不把截图里的单细胞方法分类当成龚博士的生物病理学分类表。目录应从她当前课题和已有 Zotero 收藏夹产生。
- 不安装全部 Jev Skills、浏览器自动化和系统综述工具；这些增加维护与数据边界成本，却不能解决当前“文献放哪里”的核心问题。
- 不因 `jev_classify` 返回 `auto` 就自动移动文献。它的默认概率和间隔阈值是工具策略，尚未经龚博士的领域样本验证。

## 当前限制

当前仓库只提供 Skill 路由与项目级 Jev MCP 配置；本轮没有连接龚博士的 Windows Zotero、Obsidian 或 TypeSafe 账号，也没有运行真实分类。她已有的知识库授权不延伸为 Zotero 访问和第三方元数据外发许可。后续试点应在她本机、明确选中条目的范围内进行。
