# 工作台 v0.3.1：龚博士首次使用反馈

截图反映：龚博士已在 Windows 安装并打开工作台，选择的科研知识库是 `D:\GY`。标准目录显示 `51/51`，但旧目录中的笔记不会因此自动出现在工作台；程序退出后也要重新定位知识库。截图中后续复制旧笔记的操作是否完成，尚无可核实结果。

## 本次调整

- 知识库页显示完整选择路径。目录检查明确说明 `51/51` 只代表标准目录名匹配，不代表旧笔记已经读取或迁移。
- 在研究记录、文献、RSS、查看历史归档下，可通过系统文件夹选择器分别关联知识库内的现有笔记目录。关联只保存目录位置，不读取或搬动笔记；对应范围需重新确认授权。文件夹不能位于知识库外，也不能选知识库根目录、隐藏目录或链接。实际读取/新建位置可在每项授权下展开查看。
- 桌面版可由本人主动保存知识库路径及目录关联到本机应用数据。重启后点击“使用上次知识库”找回位置，仍须重新勾选读取范围；不会自动打开笔记。“忘记上次路径”删除保存的位置。
- 首页可导出或合并导入研究任务备份 JSON；浏览器存储写入失败时展示持续提醒。备份不含 Obsidian 笔记本身。
- Codex 交接按实际打开和复制结果反馈，修正启动语弹窗偏离窗口中心的问题。

## 给龚博士的操作顺序

1. 更新桌面版后，打开“知识库”，在系统窗口选择 `D:\GY`，确认页面显示的完整路径。
2. 若旧研究笔记未在标准目录，分别点击相关范围的“关联现有文件夹”，选择 `D:\GY` 内确实存放这类笔记的文件夹；不需要为匹配而搬动旧文件。
3. 展开“查看实际读取位置”，核对后勾选所需范围并授权。页面只在进入对应模块时按需读取。
4. 如希望下次少找一次路径，点击“记住当前路径与关联”；这不会记住读取授权。
5. 在首页点击“导出备份”，把任务卡备份保存在自己掌控的位置。

本次改动没有访问 `D:\GY`，也没有移动、改名、覆盖或删除龚博士机器上的资料。已完成本机前端与桌面资源构建；Windows 安装运行和真实 `D:\GY` 目录适配仍需在她的电脑上确认。
