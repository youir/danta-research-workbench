# 文献接续第一轮更新与验证

日期：2026-10-05
状态：本地实现与回归测试完成；尚未发布 Windows 安装包。

## 这次解决什么

让龚博士从发现文献到继续阅读的过程接得上：日报、RSS 或已有笔记中的线索可以保存为阅读草稿，关联已有研究任务，记录实际读到的位置，再交给 Codex 接续。保持“今天、研究任务、文献资料、汇报制图、设置”五个工作区，不另建独立文献管理系统。

## 使用路径

1. **文献资料 → 待整理**：在已授权的 RSS 或文献笔记中选择线索；也可以从科研日报选择一条。
2. **加入我的阅读**：保存本机草稿。需要时选择已有任务；不关联任务也可以独立阅读。
3. **文献资料 → 我的阅读**：也支持手动填写题名、DOI、PMID 或来源链接；这里不会自动查询题录、取得 PDF 或宣称已读原文。
4. **记录阅读进度**：填实际阅读范围、停留章节/页码/图号、笔记和下一步。选择“本次阅读完成”前必须登记实际范围；仅读摘要不等于全文阅读完成。
5. **交给 Codex 接续**：启动语携带当前阅读卡、原发现位置、关联任务和阅读范围。按现有对话交接流程进入 Codex，粘贴并提交；不能把复制成功解释为任务已执行。
6. **返回工作台**：根据实际阅读结果更新草稿。当前没有自动回写 Codex 的阅读结果。
7. **保留与整理**：可导出单张 Markdown 草稿，或在设置中导出包含任务与阅读卡的 JSON 备份。删除本机草稿需确认，同时取消本机任务关联；原知识库文件不变。

## 与现有体系怎样配合

| 对象 | 作用 | 本轮行为 |
| --- | --- | --- |
| 日报、RSS 缓存 | 发现待核实线索 | 选中后复制所展示的线索，不改订阅或已读状态 |
| 本机阅读卡 | 个人阅读草稿与接续位置 | 即时保存；不等同于已核实证据 |
| 研究任务 | 目标、阶段、工作步骤与成果索引 | 关联阅读卡编号；多个任务可复用同一卡 |
| 私有知识库的文献获取/版本台账、阅读笔记 | 正式文献记录 | Codex 按活动课题和已有有效授权增量维护 |
| 证据矩阵 | 实际核查过的研究证据 | 实际阅读后才写，不由前端按钮自动更新 |
| 成果预览 | 预览指定产出目录的文件 | 沿用现有预览，不增加第二个文件浏览器 |

本机卡号是交接关联键，已有正式文献 ID 继续使用；不另建第二份权威文献总表。仅以题名相同不会自动合并：它可能代表预印本、发表版或其他文献。可靠 DOI、PMID、去除跟踪参数后的相同链接或同一发现记录可以复用已有卡；冲突或跨卡匹配不明确时拒绝合并，保留原数据。

## 保存、权限与恢复

- 重开后恢复页面、选中阅读卡、阅读范围、停留位置、下一步、关联任务及未填完的手动线索。
- 复用现有本机状态存储和历史恢复，不新增定时器、自动化任务或数据库。
- RSS、文献读取仍由原授权控制；更换知识库或关闭读取范围后清除页面旧数据，避免将上一个库的内容当成当前库资料。
- 原有效授权可以恢复；首次或扩大读取范围仍使用原授权流程。本轮没有为用户开启权限。
- 前端不移动、覆盖或删除知识库资料；新建归档仍单独检查原有写入授权。
- JSON 备份包含阅读摘录、笔记和登记的来源路径，属于私人资料；不包含 API 密钥、授权或原 PDF/笔记文件。应保存在本人掌控的位置。
- 旧任务备份仍可导入；新备份根据文献身份复用卡并重映射任务关联，本机已有阅读进度优先保留。标识冲突时整次导入失败，不先写入部分内容。
- 本机最多 500 张阅读卡、每卡 40 个发现来源；任务/卡状态整体沿用 12 MB 保存上限。超限会明确报错，需先导出并整理，不能无限扩张。

### 已实际操作的界面链路

在隔离测试服务中完成：手动登记虚构 DOI → 保存阅读位置/范围/下一步 → 刷新恢复 → 建立虚构研究任务 → 关联原阅读卡 → 打开 Codex 交接预览 → 导入合成日报 → 从日报加入同一文献。

复用后仍为同一张阅读卡，保留原笔记与进度，并增加日报发现来源。没有提交科研对话或执行真实研究。
