# 生信材料引导、成果来源与体系介绍

日期：2026-10-05。工作台源码准备版本 0.3.7，内容体系 1.24.0，均为本轮未发布更新。

## 本轮取舍

按前轮开源调研，吸收输入适配、过程可回看和可复现交付方式，复用已有任务/步骤/成果面板/本机桥接。未替换后端、增加工具市场、引入向量库或整套生信环境。参考：[AIPOCH Open Science](https://github.com/aipoch/open-science)、[ClawBio](https://github.com/ClawBio/ClawBio)、[BioDSH](https://github.com/sagirimo/BioDSH)；具体项目状态与许可，以前轮调研链接和源仓库核验为准，不从这些仓库复制实现代码。

## 已完成

1. 实际步骤内增加可选材料类型和六项线索：位置/编号、物种、参考版本/数据处理层级、样本分组、比较目标、交付目标。沿用原任务自动保存、备份校验、恢复和阶段快照；进入 Codex 时明确为未核验线索。
2. 原成果清单兼容可选 provenance 路径。来源 JSON 必须属于本任务目录，任务/成果编号/版本匹配；读取上限 128 KB，校验状态、退出码、时间及校验和格式。
3. 成果面板默认折叠“来源与方法”，按需展示报告状态、方法、命令、参数、环境、输入/脚本/日志索引及核查范围。命令不执行、输入索引不读取；错误来源不会阻断原件预览。
4. 点击后才能核对原件 SHA-256，上限 100 MB。服务沿用原成果目录范围、身份、普通路径、非符号链接与读取期间文件变化检查。对同一清单项读取记录和原件，避免再次查清单串用不同版本。
5. 主引导、路由、步骤约定加入真实分析交付协议，真实运行与 Methods 对齐；旧成果可不附来源，不伪造历史。
6. 新增面向龚博士的详细介绍、离线说明窗口和矢量体系图。顶部使用说明改用完整介绍；说明 Windows 版本、真实接入与执行状态的边界，并提供六分钟演示提纲。
7. 桌面分发清单补齐服务与状态模块新增依赖；说明 HTML 不长期缓存。内容安装清单按明确文件列表更新，未纳入无关本机临时文件。

## 构建与实施状态

- 本轮只做构建、语法和改动格式检查，没有新增或运行测试，没有读取真实科研知识库，没有实际执行生信分析。
- 常规桌面构建在 iCloud 下清理旧 dist/pdf-resources/cmaps 时遇到 ENOTEMPTY；改用本机临时输出目录完成同一桌面构建。正式 Windows 打包尚未运行。
- 使用固定应用版本环境完成 Vite 桌面构建；新增静态说明随 public 复制到构建结果，新增服务依赖列入 Electron 分发清单。
- 尚未推送 Git 或发布安装包，龚博士当前安装的软件不会自动获得这次更新。
