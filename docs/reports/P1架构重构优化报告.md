## 技术亮点

### 1. Feature-First Design (FSD)
参考成熟项目（如 React 官方文档、Next.js 示例）的目录组织方式，按业务功能而非技术类型组织代码。

**优势**:
- ✅ 业务功能独立，易于理解和维护
- ✅ 新功能开发时，所有相关代码在同一目录
- ✅ 删除功能时，直接删除对应目录即可
- ✅ 便于团队协作，减少冲突

### 2. 关注点分离 (Separation of Concerns)
- **展示层**: 组件只负责 UI 渲染
- **业务逻辑**: 封装在自定义 Hooks
- **配置数据**: 提取到 constants
- **样式系统**: CSS 变量统一管理

### 3. React 现代模式

### 4. 可维护性提升
- **单一职责**: 每个组件/函数只做一件事
- **命名规范**: 清晰的命名传达意图
- **类型安全**: PropTypes 或 TypeScript (可扩展)
- **文档完善**: 清晰的目录结构即文档
