# 工作台使用逻辑优化清单

检查范围：开始页、任务整理页、科研 PPT 模板与单位标识、启动语交接、研究记录、文献与信息源、知识库连接及恢复流程。

目标流程：选工作 → 补充本次任务 → 选择呈现方式 → 检查启动语 → 进入目标 Codex 工作区 → 执行、核对并接续记录。

## 优化项

| 优先级 | 发现 | 处理 | 状态 |
|---|---|---|---|
| P0 | 网页任务整理区与 Codex 工作区之间缺少实际交接。 | 工作台读取本机项目列表，在选定项目创建并尝试打开新对话，同时复制启动语。Codex 输入框仍需手动粘贴、检查并提交；不读取历史对话。 | 已完成；保留手动粘贴 |
| P1 | 科研 PPT 应先梳理科学内容，再选择视觉样式。 | 先整理主题、目标、听众与材料，再选结构、视觉模板和单位标识，最后检查启动语。 | 已完成 |
| P1 | 内容区缺少汇报准备提示，容易遗漏讨论问题或待确认信息。 | 增加可跳过的选择项和可编辑填空框架；只整理汇报人提供的真实材料，不预设结果。 | 已完成 |
| P1 | 刷新或中断后无法恢复草稿和模板选择。 | 桌面版在本机应用存储中保存任务草稿、选择项和启动语，退出重开后可恢复。 | 已完成 |
| P1 | 研究记录、文献和 RSS 页面无法查看知识库现有资料。 | 用户选择 Obsidian 文件夹后，按页面分别授权指定目录；RSS 页面读取已有缓存，不刷新订阅或抓取全文。 | 已完成 |
| P1 | 知识库归档操作需要限定写入范围。 | 查看历史归档和新建归档分开授权；新建仅写入指定目录的新 Markdown 文件，不覆盖旧文件。 | 已完成 |
| P2 | 首页“最近研究记录”入口没有对应的实时数据。 | 改为“知识库连接状态”，并直接打开知识库说明。 | 已完成 |
| P2 | Codex 启动语弹窗没有说明复制后的下一步。 | 显示目标工作区；提示新对话打开后粘贴、核对并提交；允许再次复制。 | 已完成 |
| P2 | 弹窗关闭后键盘焦点没有回到原触发位置。 | 关闭后恢复焦点，并为弹窗补充描述关联。 | 已完成 |
| P2 | 小屏顶部的图标入口含义不够明显。 | 增加悬停说明；仍需结合手机实际使用反馈决定是否显示短标签。 | 部分完成 |
| P3 | 用户希望能主动删除已保存的未完成草稿。 | 提供“清除当前保存内容”的操作，并说明清除范围和影响。 | 待设计 |
| P3 | 工作台本机桥接依赖 Vite 服务，难以交给非技术使用者长期使用。 | 打包为 Windows x64 桌面程序，内置本机桥接，生成安装包、桌面 / 开始菜单图标、发布版更新检查和 GitHub Release。 | 已实现，待 Windows runner 出包 |

## 本轮完成

- 实现了 Obsidian 文件夹选择、分项授权、指定目录读取和单独授权的新建归档。
- 实现了本机 Codex 工作区选择、新建对话、尝试打开及启动语复制；输入框仍由使用者手动粘贴和提交。
- 用 localStorage 保存可恢复的未完成任务与选择项。
- 更新了三张说明图和体系架构文档，准确标出本机桥接、Codex 交接、知识库范围与两套独立权限。
- 保留科研 PPT 的内容引导，所有选项可跳过；研究结果只根据实际材料整理。
- 新增 Electron 桌面外壳及 NSIS 安装配置，打包 React 界面与 Obsidian / Codex 本机桥接。
- 固定本机应用来源，保留跨重启任务草稿；安装后创建桌面与开始菜单入口。
- 增加 GitHub Releases 版本检查、Windows 安装包与 SHA-256 校验文件的自动发布流程。
