# 工作台 v0.3.2：知识库授权记忆

## 龚博士使用时的变化

首次确认知识库和具体范围后，桌面版会在本机保存知识库位置、目录关联及逐项授权。下次打开工作台，进入“知识库”，点击“核对并继续使用上次知识库”即可恢复；也可重新选中同一文件夹。恢复过程只检查路径、文件夹身份和授权目录是否仍匹配，不会自动打开笔记。

若某个已关联目录丢失或发生变化，工作台只暂停受影响的授权，其余范围继续可用。可在该项下重新关联正确文件夹并确认变化后的实际读取路径。若整个知识库被替换或移动，需重新选择并核对范围。点击“断开并清除本机授权”会清除已保存的位置及授权记录。

## 旧版升级边界

v0.3.1 的本机记录只含路径和目录关联，没有保存已勾选的授权项。新版无法据此推断她过去同意了哪些权限；首次升级后需要由她确认一次，随后才可跨重启恢复。不会根据聊天截图或目录存在情况自动授予权限。

## 数据边界

授权记录保存在桌面应用的本机用户数据目录，不进入 Git 或云端。保存的是路径、目录关联、知识库文件夹身份和逐项授权的路径列表，不含笔记内容。读取仍在进入相应页面时才发生；归档写入仍需本人单独授权且只新建文件。
