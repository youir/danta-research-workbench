# 科研工具地图

本图是候选目录，帮助把研究问题、数据形态、分析步骤和可用工具连起来。它不代表龚博士已经开展这些研究、拥有相应数据、掌握工具或认可具体方案。交接资料中的研究线和工具匹配建议尚未逐项核验；研究方向以本人确认的信息为准，工具适用性以当前任务和官方资料为准。

## 使用规则

- 先写需要回答的问题和手头数据，再找工具；不要为了使用工具倒推课题。
- 下表的“候选用途”是需要核验的起点。项目维护状态、许可证、系统要求、成本、输入格式和方法适用范围可能变化，使用前查看官方文档/论文并记录访问日期。
- 状态只表示当前环境中实际做过的检查：未验证、部分可用、已验证可用、不可用。装上软件或找到 skill 不等于能完成分析。
- 只有进入当前方案的工具才登记到 `资源与约束.md`。记录检查动作、日期、版本、实际输入输出、限制及降级路径；未实际运行不写“已验证”。
- 方法学记录实际使用的工具、版本/提交、关键参数和环境；预测或结构计算结果标为相应证据状态，不单独当作实验验证。
- 交接资料建议的 PRIDE/ProteomeXchange、SDRF、自动日报等做法均不是默认要求。按研究类型、期刊/资助要求、数据授权和本人选择决定；不创建自动写入流程。

## 候选目录

以下工具及其对应关系来自 2026-09-28 交接材料，尚未独立核验。保留为探索入口，不构成购买、安装或采用建议。

| 领域/数据形态 | 候选工具 | 交接材料提出的用途（待核实） | 采用前要确认 |
|---|---|---|---|
| 蛋白质组、化学蛋白质组、ABPP | FragPipe、MSFragger、Philosopher | 搜库、蛋白质组及探针实验数据分析 | 仪器数据格式、实验设计、标记/富集方案、工作流是否匹配、硬件与许可 |
| 蛋白质组流水线 | nf-core/quantms、Nextflow | 可复现的定量分析流水线 | DDA/DIA/TMT等采集设计、容器环境、参考库和存档要求 |
| DIA 质谱 | DIA-NN | DIA 数据分析 | 仪器、采集模式、软件许可与版本、同现有平台的兼容性 |
| PTM 组学 | PTM-Shepherd、PTMProphet、MSFragger-Labile、luciphor2 | 修饰搜索与位点定位 | 修饰类型、谱图质量、定位阈值、目标软件链及版本 |
| 蛋白质组统计 | MSstats、MSstatsTMT | 定量数据统计 | 实验设计、缺失值机制、对比、重复结构与模型假设 |
| PTM 位点候选 | MusiteDeep | 位点预测与候选排序 | 训练数据/适用域、物种与修饰类型；仅作为假设线索 |
| 蛋白结构 | ColabFold | 结构预测或结构背景查看 | 序列、模型置信度、结构适用范围、数据上传规则；结构不等于功能验证 |
| 化学信息 | RDKit、ChEMBL 客户端、PubChemPy | 分子结构处理、化合物与活性信息检索 | API/数据许可、标识符和来源日期、信息覆盖与版本 |
| 量子化学/荧光探针 | PySCF | 计算化学性质或激发态相关问题 | 计算模型、基组、计算资源及与实验读数的对应关系；不默认预测真实荧光表现 |
| 分子对接 | AutoDock Vina | 配体结合模式探索 | 受体结构质量、质子化/构象、参数及验证对照；结果属计算推断 |
| 分子性质预测 | admet-ai、DeepChem、MoleculeNet | ADMET/QSAR 候选排序 | 训练集、适用域、终点定义和校准；预测不作毒性结论 |
| 单细胞转录组 | Scanpy | 单细胞数据处理与分析 | 是否确有相应数据、实验批次/设计、分析流程与统计假设 |
| 毒性预测/公共数据库 | OPERA、CompTox/ctxR | 理化性质、毒理预测或公开数据库查询 | 官方项目/接口现状、预测终点、适用域、数据版本与引用方式 |
| 毒代动力学/IVIVE | httk | 体外到体内外推相关分析 | 暴露情境、化合物参数、模型假设、单位和适用范围；不是直接风险结论 |
| 剂量反应 | BMDS/pybmds | 基准剂量建模 | 终点、剂量设计、模型选择、拟合诊断、软件当前版本和监管指南 |
| 系统综述偏倚图 | robvis | 偏倚评估结果可视化 | 适用的评估工具、输入编码和图表解释 |
| 文献问答 | PaperQA/PaperQA2 | 对用户提供的文献库做检索辅助 | 是否可本地运行、隐私和模型服务、引用定位质量；每条引用回原文核对 |
| 数据与实验记录 | DataLad、eLabFTW | 数据版本管理或电子实验记录 | 机构政策、部署维护、隐私/安全、团队接受度与长期成本 |
