# 论文贡献表达与防御性写作适配

用于本轮论文起草、改写、润色、压缩或论证组织。先按本技能的证据边界确定哪些贡献真正成立，再读取固定版本的 `anti-defensive-writing/SKILL.md`，用其方法优化叙事与语言。

## 如何加载

优先读取当前工作区已安装的同级 `../anti-defensive-writing/SKILL.md`（相对 `danta-bio-paper-writing/` 技能根目录）。若尚未安装，读取发行源码中的 `vendor/skills/anti-defensive-writing/SKILL.md`；找不到时说明未加载，按现有写作规则完成本轮，不假称已调用。无需联网或 API Key，不把稿件发送给 Jev 或新的外部服务。

上游固定提交、许可与文件摘要在 MANIFEST.json 和第三方来源说明中记录；原文不改，生物医学适配集中在本文件。新安装和内容更新会沿用技能依赖部署它，使用者不用记名称。

## 触发范围

- 论文起草、论文润色/修改、中英文学术改写；摘要、引言、结果、讨论、结论、标题与图注的写作。
- 压缩论文、重组论证、去除论文 AI 味或不必要的自我否定；论文修回文字及审稿回复的表达编辑。
- “润色一下”“改这一段”可在已明确是论文稿件的上下文中触发；只有“润色”而对象未明时，不套论文叙事。
- 数据分析、实验执行、开题选题、文献摘要/精读、日报、组会记录及纯译文忠实核对不触发。用户只要核对事实、批评研究缺陷或直译时，按所请求的任务处理，不把它改成贡献宣传。

## 生物医学适配优先于上游修辞建议

1. **突出有依据的贡献。** 整理为研究问题 → 经核查的知识缺口 → 本研究贡献 → 对应证据；不依据文风补造创新、首创、机制证实或临床可用性。没有领先优势也可清晰报告可信的阴性、复制或描述性研究价值。
2. **不改变事实或报告范围。** 上游“删掉、弱化、移动”仅用于冗余背景、重复过程和与问题无关的文字；不删除原始记录，不隐去应报告的阴性/不显著结果、预设主要终点、不良事件、重要反例或影响结论的局限。全文重排先标出实质改变，保留原稿。
3. **不事后挑指标。** “换评价维度/重定义故事”可以用于收窄文字主张或提出后续研究建议，不得静默更换预设终点、比较组、统计阈值或只挑阳性结果。探索性发现明确标探索性；实际研究设计照实报告。
4. **中性表达不等于掩饰。** 可去掉无信息量的“遗憾的是”“必须承认”，但“下降”“未改善”“未达到预设终点”等真实观察仍准确写出。“仅”描述真实范围时可以保留；不机械禁词。不能给未记录的失败补造“合理权衡”解释。
5. **证据强度保持一致。** 样本量、效应量、置信区间、统计量、引文及因果语气保持原意；关联不升级为机制，统计不显著不等于等效或无效。摘要和结论保留理解核心发现所需的范围与不确定性。
6. **修回正面回答。** 逐条回应真实审稿问题；不能因“不主动示弱”跳过问题、否认实际不足，或声称补实验/修订已完成。仅写实际改动与位置，未完成写建议或计划。

遇到冲突，以用户本轮要求、真实研究记录、适用报告要求和工作台证据纪律为先；上游作为表达方法，不作为更改科学事实的依据。

## 最短执行与交付

只改一段时，内部检查本段主张、证据与必要限定，直接给修订稿及简短实质修改说明；不强制访谈、打分、全稿审查或新建步骤文件。长稿依既有 workflow 对齐主线。已有统计、审查和去 AI 味技能按需使用，不重复启动相同编辑流程。

例如原句“遗憾的是，本队列未观察到显著差异”，可去掉情绪评价，保留“本队列未观察到统计学显著差异”及已有统计信息；不能改写成“证实两组无差异”。
