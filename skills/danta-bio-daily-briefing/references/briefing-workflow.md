# 日报工作流程

## 1. 确定本轮窗口

按龚博士指定的起止时间；未指定时使用“自上一份日报完成后至本次运行”的窗口。第一次运行只报告可核实的近 24 小时窗口，并注明来源的实际检索/更新覆盖。使用 vault 中已有日期时区设置；找不到时沿用本轮系统时区并标明，不猜居住地时区。

## 2. 收集来源而不扩权

先检查本轮实际可用工具和获准目录。可用材料包括她已主动保存的 RSS 线索、已同意的公开文献检索结果、以及本轮明确给出的论文/研究问题。先读元数据和摘要；全文仅在可访问且适合本轮目标时阅读。不得顺手扫描其他文件夹或把敏感/未发表资料提交给第三方。

如 RSS 尚无订阅或本轮没有来源，不调用不存在的工具。说明可以在 Obsidian 的“龚博士科研信息源”中添加她选择的 RSS/Atom 来源；不要替她代选、订阅或开启定时刷新。

## 3. 去重、核验与取舍

- 用 DOI、PMID、预印本 ID、稳定数据库 ID 去重。题录/版本变动则保留版本关系。
- 核对题名、日期、来源、链接及文章类型。来源间冲突时保留冲突，不强行择一。
- 按与龚博士已确认问题的相关程度、结果/方法是否改变理解、来源质量、信息新颖性筛选。不能确认个性化相关时明确写“领域动态，关联待确认”。
- 重点项最多 3 条，其他栏最多各 3 条。每条只讲一件事；弱线索、重复新闻和无从判断的条目静默省略。
- 检查每条是否有真实来源、日期、访问深度及准确的证据标签；缺一关键项则降低置信表述或省略。

## 4. 编排一页

依次包括：日期与一句“今天的研究脉搏”；有来源数字支撑时展示同行评审/预印本/指南数据库等分类计数；“值得留意”（最多3条）；按需出现“待核验”与“组会可讨论”；页尾说明来源及覆盖限制。

“今天的研究脉搏”只综合本次实际收集到的项目，不描述虚构的学术热点。没有数据就显示对应空状态，不画装饰性数据图。没有条目的版块连标题一起省略。用户以 `Sections:` 或直接描述要求附加版块时，只基于本轮实际来源添加，按其指定顺序排列。

日报用中文时采用安静、紧凑、可扫读的单栏页面，标题、来源、证据类型和一句关联一眼可见。所有内容写入一个自包含 HTML 文件，文本进行 HTML 转义，外链仅允许安全的 HTTPS。报告留在私有 vault，不对外发布。

## 5. 反馈和知识库写回

默认不改任务清单、研究状态、Idea 画布、画像、证据矩阵或RSS原始线索。龚博士指出某条有用/无关/已经知道时，只在她明确要求的偏好记录或报告反馈中记录；若要升级为证据或决定，应先核对原始文献并走对应流程。不要将自动摘要直接当作持久记忆。

## 6. 结束说明

简短给出报告文件链接、实际覆盖的来源类型/时间窗和一项重要限制。若无来源，明确这是空壳/状态页，尚未形成今日生物医学动态总结。
