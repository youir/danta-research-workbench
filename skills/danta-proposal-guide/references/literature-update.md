# 文献增量复盘

按用户指定时间窗或自上次检索起复盘；没有上次记录就明确“首次基线”。已选课题问题与资源优先，未定时围绕当前困惑探索。此流程是按需运行，不自动定时、不要求每周凑篇数或新选题。

## 检索与读取

复用既有检索CSV及证据矩阵，检索式、数据库/工具、日期、过滤条件、实际返回和限制写入原记录。按DOI/PMID规范化去重（去URL前缀并统一大小写），无稳定标识时比较题名、作者、年份但保留待核实，不能合并不同研究。预印本/正式版、更正与撤稿建立版本关联，不作为独立证据重复计数，也不擦除旧解释。

`我的开题/03_文献与证据/文献获取与版本.csv` 只管理文献身份、获取和版本状态；证据ID引用原矩阵。字段未知留空/待核实，状态仅表示实际检查：未尝试/元数据/仅摘要/全文已获取/需机构访问/失败；记录访问与核验日期。可下载不等于已读，已读章节记具体范围。只读摘要不能编方法细节或结果数值。缺全文时继续可完成的工作，列待获取项。

筛选依据是问题相关性、设计与证据质量；期刊分区/出版社偏好仅在用户或机构确有要求时单列，分区记录年份、类别与来源，不能猜测或把它当研究质量证明。保留反证、阴性与更正信息，不只挑符合假说的文献。

## 增量输出

用短表连接“新增/修订/重复/未取得 → 文献ID及证据ID → 支持、削弱或限制哪个主张 → 改变了什么/未改变什么 → 下一步”。补充重复文献的理由和未解决的冲突。零篇符合条件或没有新认识都如实报告，不凑数量；近期样本不足时不宣称领域趋势。

本人已有问题得到新证据支持后，可提出待讨论的研究问题及其来源，不固定每周3–5题、不自动排名或变更工作基线。组会从增量表选出最影响判断的材料。需要Excel时从权威CSV导出标日期的阅读视图；不同时维护另一本可写总表，不把导出副本当权威记录。
