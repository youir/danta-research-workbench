# 文献增量复盘

按用户指定时间窗或自上次检索起复盘；没有上次记录就明确“首次基线”。已选课题问题与资源优先，未定时围绕当前困惑探索。此流程是按需运行，不自动定时、不要求每周凑篇数或新选题。

## 检索与读取

复用既有检索CSV及证据矩阵，检索式、数据库/工具、日期、过滤条件、实际返回和限制写入原记录。按DOI/PMID规范化去重（去URL前缀并统一大小写），无稳定标识时比较题名、作者、年份但保留待核实，不能合并不同研究。预印本/正式版、更正与撤稿建立版本关联，不作为独立证据重复计数，也不擦除旧解释。

`我的开题/03_文献与证据/文献获取与版本.csv` 只管理文献身份、获取和版本状态；证据ID引用原矩阵。字段未知留空/待核实，状态仅表示实际检查：未尝试/元数据/仅摘要/全文已获取/需机构访问/失败；记录访问与核验日期。可下载不等于已读，已读章节记具体范围。只读摘要不能编方法细节或结果数值。缺全文时继续可完成的工作，列待获取项。

记录更新后可在现有工作区运行 `python3 "<本技能目录>/scripts/validate_research_records.py" <工作区根路径>` 做只读离线校验。它检查现有两份 CSV 的列和标识、证据ID关联、DOI/PMID 重复版本关系、实际阅读范围及显式测试来源。失败时先修正记录或说明未决项，不把失败记录纳入正式综合判断。校验通过仅说明这些可机械检查的结构一致；不能证明论文支持主张、两项研究队列独立、agent 真实执行或分析获得本人授权。

筛选依据是问题相关性、设计与证据质量；期刊分区/出版社偏好仅在用户或机构确有要求时单列，分区记录年份、类别与来源，不能猜测或把它当研究质量证明。保留反证、阴性与更正信息，不只挑符合假说的文献。

遇到两篇公开论文结论看似冲突时，可按 [Jev 接入规则](jev-search-integration.md) 先定位相应原文段落，再辅助比较两段说法。只发送可公开表达的问题和短片段；把物种、模型、人群、终点、检测方法与时间窗逐项核对后，才记为相同结论、真实冲突或不可直接比较。Jev 未连接或资料不可外发时直接按原文进行复盘。

## 增量输出

### 从工作台接续阅读

“我的阅读”里的卡片是本机阅读草稿与任务关联索引，不是第二份权威文献库。工作台只保存本人选中的 RSS / 日报线索、已有笔记摘录或手动登记来源；卡片编号用于交接，不能代替正式文献ID。RSS 已读、日报标注的阅读深度与本人实际读论文的范围分别记录。

接到阅读交接时，先核对本人记录的实际阅读范围、停留位置、下一步、原笔记位置及本次研究任务。沿用已存在且未撤销的授权，解析唯一私有工作区和活动课题；不因新对话或重开重复索取授权，也不扩大范围。已有原笔记继续增量维护，已有获取/版本台账和证据矩阵继续使用原文献ID；有可靠 DOI/PMID 时核对同篇与版本关系，不按同题名强行合并。

没有明确课题关联的独立阅读先留作草稿，不自动归入某课题证据。只有实际读取并核对原文后，才更新实际阅读范围、原文定位、支持或限制的主张及未决项。返回工作台时简要列出：本次读到哪里、读取了哪些范围、实际更新的原笔记/台账路径、下一步，以及仍未核实的事项。前端本机草稿与 Codex 写回目前没有自动双向同步；不得宣称已同步。可由本人按上述摘要更新阅读卡。

用短表连接“新增/修订/重复/未取得 → 文献ID及证据ID → 支持、削弱或限制哪个主张 → 改变了什么/未改变什么 → 下一步”。补充重复文献的理由和未解决的冲突。零篇符合条件或没有新认识都如实报告，不凑数量；近期样本不足时不宣称领域趋势。

本人已有问题得到新证据支持后，可提出待讨论的研究问题及其来源，不固定每周3–5题、不自动排名或变更工作基线。组会从增量表选出最影响判断的材料。需要Excel时从权威CSV导出标日期的阅读视图；不同时维护另一本可写总表，不把导出副本当权威记录。

## 新证据影响已有成果

实际引用时在证据导航维护课题ID、主张ID、证据ID/版本、输出路径及位置、核验日期，不另造文献总表。更正/撤稿/反证或阅读范围升级先核验原文与出版状态，再沿引用回查方案、组会、论文、图注和记忆。记录受影响表述、修订建议、尚未复核项，保留旧版。只修订指定成果，不静默重写已交付文件；不能把一次更新说成整个研究已验证或全部引用已复核。
