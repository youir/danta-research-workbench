# 资料与环境盘点

## 0. 初始资料扫描：先授权，再读取

初次了解龚博士的研究工作时，可以主动提出一次可选的“初始资料扫描”，帮助她从文章、课题材料和汇报中快速建立有来源的工作概况。提出扫描不等于已获授权；在读取内容或递归列出文件前，先请龚博士本人确认具体文件夹、包含的文件类型/子目录、扫描目的，以及是否同意在当前私有知识库新建一份摘要报告。一次同意只覆盖说清楚的范围，不自动延伸到父目录、相邻目录、其他 vault 或后续新材料。

可以这样询问：

> 龚博士，如果你愿意，我可以只读扫描你指定的一个科研资料文件夹，梳理研究主题、主要项目、常用方法、当前进展和待确认问题，并在本知识库新建一份带来源的摘要。原文件不会被改动。请告诉我具体文件夹、允许读取的文件类型或子目录；聊天/邮件、个人文件、患者可识别信息和原始数据默认排除。Codex 对话可能使用云端模型处理内容；如果当前环境会把文件内容发送到云端或第三方，我会先说明并另行征得同意。你是否授权我按上述范围扫描并生成摘要？

若回答含糊、没有明确目标路径或未授权保存摘要，先补问，不扫描。明确拒绝就不再推进扫描，可用龚博士亲自提供的摘要继续工作。部署者/亲友的请求不代替龚博士对其研究资料的授权。

得到明确授权后：

1. 只递归读取指定位置及获准的子目录/文件类型；排除未授权的聊天、邮箱、个人文件、患者可识别信息、凭据和原始数据。若发现可能包含这些内容的文件，跳过并在报告中只记数量/类型，不引用敏感片段。
2. 原件只读，不移动、重命名、修改、删除或上传。若执行环境的文件处理或模型推理涉及云端/第三方，且授权前未明确说明并获准，停止内容读取；不可确认处理位置时如实说明，不承诺“仅本地处理”。
3. 记录实际扫描路径、日期、文件类型、数量、阅读范围、跳过项、解析失败和限制。只对成功读取的内容提炼重点；PDF/OCR、扫描件、表格和演示文稿注明具体覆盖范围。
4. 摘要区分“材料明确写明”与“助理推断”，标注文件路径/名称和页码、章节或幻灯片范围；描述作者身份、当前进展、资源可用性和偏好时，不从文风或第三方文章推定为龚博士的个人事实。
5. 在主课题“研究背景”中新建或更新初始资料扫描报告；不要直接把未核实推断写进权威研究画像。先把报告交给龚博士校正，由她确认后再更新研究画像、资源约束或长期记忆。保留冲突与未知，不把摘要等同于全文掌握。

报告模板见 vault 中主课题研究背景的 `04_初始资料扫描_Initial-Scan.md`。没有模板时按上述信息在工作区内新建，不复制原件。

## 1. 范围与优先级

只列工作台原始资料目录及用户明确指定的路径。先记录文件名、类型、主题和预期用途，避免把全部附件一次性读入。

阅读顺序：学校模板/评分要求 → 课题组研究方向及用户目标 → 样本平台与周期 → 关键综述/原始研究 → 预实验 → 导师意见。用户的明确优先级可以调整此顺序。

对每份资料区分未读、已读元数据、已读摘要、已读指定章节、已读全文、解析失败。长文可以先定位章节再精读，必须写明覆盖范围。扫描 PDF 需要 OCR 时报告障碍；读取表格要检查工作表和单位；不要把文件可打开当作内容可用。

## 2. 可逐步填写的画像

疾病/器官、病理过程、机制型/临床型/计算型/未定、感兴趣现象、导师主线、本人技能、样本及配套信息、平台/模型、合作资源、经费、开题与毕业时间、学校格式与评审标准。

各项保存值、状态（已确认/暂定/未定/待核实）、来源及日期。首次优先问研究阶段、现有资料、硬性期限；不要十几个问题一起问。

## 3. 科研资源审查

- 样本：来源、可用数量范围、入排标准、保存方式、组织类型、病理复核、随访/临床字段、配对性、缺失情况、使用权限。
- 平台与模型：已成熟/待建立/依赖合作；近期可用性、排期、负责人、成本及替代方案。不要索取账号或密钥。
- 预实验：原始数据、处理过程、重复和分析单位、对照、批次；区分已完成与计划。
- 计算资源：数据字典、文件格式、分析环境、存储/算力、访问限制；只检查当前工作实际需要的内容。

## 4. 两类环境分开判断

工具环境：技能文件存在、客户端是否发现、检索是否实际返回结果、PDF 是否可读取、统计软件是否可运行。
科研环境：样本与平台是否真实可获得、技术是否成熟、时程是否匹配。这些不能靠电脑脚本自动验证。

基础环境脚本只给静态检查；首次真实任务需做最小能力验证。失败时记录失败与替代路径，不反复安装无关依赖。

## 5. 准备度报告与门槛

报告包括：阅读范围、已掌握事实、冲突和未知、工具状态、关键资源约束、最优先补充事项和建议下一步。

允许三种结论：
- 尚不能有依据地探索：连方向范围或可讨论的问题背景都缺失；先访谈。
- 可在显式假设下探索：有问题背景，但样本/平台等未定；提出分支，不收敛最终题目。
- 可以开展候选题论证：用户确认画像，有足够材料界定问题和资源边界；仍需文献查新与验证。

用户确认报告或明确接受缺口后记录其原意、日期和范围；不要反复确认。若画像仍有实质冲突，先说明对下一步的影响。

用户尚无方向也可先获得帮助：直接解释概念或示范如何拆解一段材料，明确示例是假想，不写入真实画像。资源未定限制的是可行性结论，不是知识解释和暂定问题比较。不要把盘点变成必须先回答完的问卷。
