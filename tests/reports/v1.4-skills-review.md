# 科研 Skills 首轮对比测试

日期：2026-09-24。结论：保留 danta-proposal-guide 为唯一主引导入口；codex-research 列为优先试用的文献论证模块；nature-reader 列为精读候选。本轮不支持“新 skill 明显优于原系统”。用户随后授权将两个模块及共享依赖按需打包，未纳入整套 Nature Skills。

## 测试怎么做

三个独立子 agent 读取同一虚构案例，分别显式加载一个 skill 及按需参考文件；生成结果前未互读。默认模型未主动覆盖。每组一次调用，包含三个固定情境：模糊兴趣探索、错误主张与缺失数字核查、用户暂停实验讨论后的解释。之后两个 agent 交叉检查结果，由主 agent 汇总。

共同输入来自两篇公开论文的 PubMed 摘要和图注转述，不是全文：
- S1 Dixon et al., Cell 2012，PMID 22632970：https://pubmed.ncbi.nlm.nih.gov/22632970/
- S2 Yang et al., Cell 2014，PMID 24439385：https://pubmed.ncbi.nlm.nih.gov/24439385/

下载作者网站 PDF 返回403，Europe PMC全文接口返回500；直接抓取PubMed所得页面未作为有效论文文本使用，改由网页读取工具核实摘要/图注。本轮主动收窄为“受限证据问答与引导”，未把访问失败记为学术反证。未使用真实研究资料，未更改用户研究档案。

## 接入建议

1. 保留现有主引导，避免多个总控同时介入。
2. codex-research：候选试用，用于来源层级、矛盾证据和研究空白论证；实际检索能力另测。
3. nature-reader：候选试用，下一步用可读取PDF测试关键图、图注、正文定位及中文解释。
4. researchwrite：本轮未测，不纳入实测结论。方向形成后再测试开题写作。
5. 从本轮即可借鉴的规则：区分“论文数/数据库条目数/独立证据数”；材料未提供不等于原文不存在；解释方向不明时明确标为假说。

后续若要宣称完整能力已验证，至少补做全文/PDF图文测试、跨会话恢复、多个学科案例，以及蛋挞或领域导师的真实使用反馈。v1.4已完成文件打包与路由接入；这不扩展上述能力验证范围。

## 限制

仅一个虚构案例，每候选一次；三个情境在同次调用中呈现，不是实际逐轮对话。无无技能基线、无随机重复、无盲评，也无领域专家评分；案例本身明确了证据边界，因此无法把守规则表现完全归因于skill。T1/T3超出nature-reader的主要职责。未测完整检索、全文翻译、OCR、图像裁切、创新性判断或科研实际产出。

本仓库附公开虚构案例和预先定义协议；逐候选原始输出保留在本次本地测试记录包。
