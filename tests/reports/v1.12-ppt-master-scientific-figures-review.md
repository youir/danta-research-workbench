# v1.12 科研图与 PPT Master 独立审阅

日期：2026-09-26。由并行审阅 agent 对当前工作台、固定版 PPT Master v6.6.0 源码和官方包布局作只读审阅；未编辑产品文件、未读取真实研究资料，也未发送任何消息。

## 结论

PPT Master 能承接流程图和机制图的矢量绘制与部分 PowerPoint 原生对象转换；它提供通用图形/连接线能力和 flowchart 图型说明，不提供生物病理学的证据判断规范。科研可靠性必须由工作台的包裹流程补足。

## 审阅意见与处理

- 增加节点—关系—来源表：记录模型语境、关系方向、证据状态、来源位置和限制；已加入科研图制作流程和 Obsidian 图稿模板。
- 机制图明示线型与箭头含义：关联不等于因果，直接支持、推断、假说和未知可区分；来源没有说明的激活、抑制、结合、定位和运输不补画。
- 实验设计、样本流程、病理图版和定量图分开检查：计划/结果、样本数量、真实原图处理及数据/统计来源需分别回链。
- 交付分开做科学内容与文件视觉 QA：只有受支持的 SVG 元素承诺可转为原生可编辑对象；复杂对象和显微位图须单独说明并保留图源。
- 上游可选在线检索、网页搜图及图像生成默认关闭；需要外发研究材料时须先披露并取得龚博士明确授权。
- 完整 PPT Master 安装包约 62 MB；工作台固定 v6.6.0 官方 Release SHA-256，首次制图按需下载到当前私有工作区；上游 attribution guard 与许可文件完整保留，不裁剪上游包。
- 不默认安装上游完整 requirements。PyMuPDF 被上游标注为 AGPL-3.0，故只在特定 PDF 转换确有需要时另行评估。

## 验证范围

固定官方 Release ZIP 的摘要校验、安全解压和 attribution guard 在临时工作区通过；Codex 提供的 Python 3.12.14 可加载上游 SVG→PPTX 工具入口，符合其 Python 3.10+ 要求。发行测试覆盖技能依赖边界、知识库结构、模板/链接完整性和本地安装冲突保护。

本次未制作含真实研究内容的机制图，也未验证龚博士设备上的 PowerPoint 渲染、投稿期刊规范或任何生物学结论；正式图稿仍需她核对科学关系与模型语境。
