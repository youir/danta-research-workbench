# 龚博士科研工作台 · 本机前端

以思维引导为起点的本机工作台前端。现阶段提供可运行的交互壳，用于检视信息结构、工作入口与启动语流程。

## 启动

在龚博士自己的 Windows 电脑上，从公开 GitHub 仓库下载并解压后，进入 `apps/danta-workbench-ui`。需要 Node.js 20.19 或更新版本。可以双击 `启动工作台.bat`：首次启动会安装依赖，然后自动打开本机浏览器。关闭启动窗口即可停止工作台。

也可以用终端启动：

```bash
git clone https://github.com/youir/danta-research-workbench.git
cd danta-research-workbench\apps\danta-workbench-ui
npm install
npm run start
```

浏览器地址为 <http://127.0.0.1:5173/>。服务只绑定她自己的电脑，不对局域网公开。如果她使用 macOS，也可运行 `npm run dev` 或双击 `启动工作台.command`。

## 页面与交互

- **开始：** 输入观察、困惑或决策；从选题思路、论文写作、科研 PPT、组会准备 / 复盘、生物科研日报五个独立入口进入。每项工作都有单独页面，包含新建讨论、Codex 对话状态和本次工作文件区。
- **研究记录：** 当前仅展示连接状态，不生成假记录。
- **文献：** 说明 RSS 线索如何进入人工复核流程；目前没有接入数据源。
- **知识库：** 说明后续 GY 连接范围；当前目录选择演示仅记文件夹名，不读取或上传资料。

## 当前边界

工作台在龚博士电脑上启动后，才会在她的电脑本地运行。Codex 对话、GY、RSS 与本机 agent 尚未连接；不会自动扫描文件、改写知识库、调用模型或保存研究内容。每个工作区选取文件时仅暂存文件名，刷新页面即清空；Codex 对话须由龚博士主动复制启动语后继续。后续接入前，应先确认本机权限、资料路径、实际技能调用方式和授权提示。
