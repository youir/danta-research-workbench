# 龚博士科研工作台 · 本机网页

网页用于快速选择任务、整理启动语、查看流程方法和检查 GitHub 更新。Codex 仍是实际的科研协作入口；网页不会自动启动 agent、读取 GY、同步 Codex 对话或执行 Git 更新。

## 在 Windows 启动

先克隆或更新仓库，再双击 `启动工作台.bat`。首次启动会安装依赖并打开本机浏览器。需要 Node.js 20.19 或更新版本。服务只绑定 `127.0.0.1`，不向局域网开放。也可以在此目录运行：

```powershell
npm install
npm run start
```

浏览器打开 `http://127.0.0.1:5173/`。给 Codex 的完整更新和启动话术见[部署说明](给Codex的更新与启动指令.md)。

## 页面结构

- **开始：** 写下一个研究问题，或打开选题、论文、PPT、组会准备 / 复盘、生物科研日报五个独立工作区。每项工作都有自己的可编辑草稿、启动语和文件名清单。科研 PPT 工作区提供四套病理科研汇报模板的封面预览和 PPTX 下载；选择后会将模板名及文件路径写入启动语。可选内置海军军医大学或复旦大学上海医学院 Logo，也可选择暂不添加或在 Codex 对话提供其他获授权的标识。未选时，启动语会先引导确认实际汇报单位。
- **研究记录：** 展示接入状态；当前不读取 GY，也不显示演示记录。
- **机制图：** 单独入口，也能从 PPT 工作区进入。输入简短需求后生成绘图启动语；“查看制作过程”展开五步方法说明。BioTender 是可选技能索引，BioRender 是外部绘图平台，两个链接都不会携带研究内容。
- **文献与信息源：** 说明 RSS 来源与网页当前未连接的状态；RSS 线索仍由 Obsidian 插件收集。
- **知识库：** 可选择现有 GY 文件夹查看所选名称，但此原型不会扫描、读取、上传或写入资料。
- **检查更新：** 手动比较运行网页对应的 Git 提交与 GitHub `main`，并可复制更新指令给 Codex。浏览器不能自行执行 `git pull`；Codex 会先检查分支、工作区和本地修改。

## 当前数据边界

草稿、所选文件名、当前选择的 PPT 模板、Logo 和知识库名称只保存在当前页面内存；刷新网页后清空。四套 PPTX 和两份校徽文件随工作台发行，下载和选择不读取研究资料。自备 Logo 需在 Codex 对话中另行提供；网页只保存所选文件名，不读取文件正文。网页尚未接入 Codex 历史对话、GY、RSS 数据或本机职责 agent。请在 Codex 对话中粘贴已确认的启动语继续协作。

## 开发与检查

```bash
npm install
npm run check
npm run start
```

导航和主要表单适配键盘及窄屏；更新面板会报告网络错误或缺少 Git 元数据，不会把无法比较的状态误报为“已是最新”。
